## [1.0.0] - 2025-01-01
### Added
- Recursive website crawler with configurable depth
- Markdown file scanner for broken links
- Concurrent requests with configurable parallelism
- Color-coded terminal output (OK / broken / redirect)
- JSON and CSV report export
- Anchor fragment validation
- `--ignore` glob pattern support
- CI mode with non-zero exit on broken links
- `--no-external` flag to skip external URLs
- Achievement tracker and roadmap scripts
- GitHub Actions CI workflow
- Devcontainer configuration for Codespaces
